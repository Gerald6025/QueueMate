# QueueMate

A modern, mobile-first real-time queue management system built with Next.js, TypeScript, and Tailwind CSS.

## Features
- **Customer Kiosk**: Search companies, join queues with instant ticket issuance, track queue position, and estimate wait times.
- **Company Portal**: Manage company profile, operating hours & queue acceptance windows, manage staff members, and monitor real-time queue metrics.
- **Staff Portal**: Dedicated mobile portal for counter staff with staff ID & PIN authentication.
- **Multi-Role Experience**: Seamless switching between Customer, Company Admin, and Counter Staff.
- **Dark Mode**: Tailored dark theme across every component and view.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience the application.

## Technologies Used
- Next.js 15
- React 19
- TypeScript
